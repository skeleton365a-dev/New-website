# Feature map

## BISE curriculum workspace
- Class 9, 10, 11 and 12 views
- Science, Humanities / Arts, ICS, Pre-Medical, Pre-Engineering, Commerce and Matric-Tech group labels where relevant
- Individual subject cards and subject workspaces
- Personal chapter list
- Official PECTAA, BISE Lahore and eLearn source links

## Study material import
- PDF (selectable text; PDF.js loaded from CDN)
- TXT, Markdown and CSV
- Class / subject / chapter tagging
- Imported file library and deletion
- Scanned PDF warning (OCR required)

## Syllabus-based assessment
- Select class, subject, chapter and source file
- 5, 10, 15 or 20 questions
- Easy revision, board exam or challenging level
- AI MCQs grounded in selected imported source text
- Manual MCQ authoring
- Chapter question bank
- Score, answer review and explanations
- Quiz history
- No default random sample quiz

- Dashboard and progress summary
- Planner and reminders
- Subjects and chapter completion
- Notes
- AI Tutor and Problem Solver
- Flashcards
- Focus Room
- Study Tracker
- Weekly timetable
- Resources, goals and journal
- Local backup import/export
